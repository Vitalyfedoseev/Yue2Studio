# Студия v2: многодорожечный таймлайн в духе Suno Studio + Audacity-операции

Скоп по ответам: дорожки = основной трек + слои овердаба + **импорт своего аудио**; аранжировка — **Audacity-стиль** (копировать/вставить/дублировать/тишина/поменять/фейды через выделение, в набор изменений); **компинг** версий; экспорт (выделение + мультитрек-zip); прослушать набор; клавиши + undo/redo + snap. Всё поверх текущего стека (vanilla JS, numpy/ffmpeg, SQLite).

## 1. Хранилище и импорт аудио (store.py, server.py)

- store: колонка `lane_of` (дорожка-слой, привязанная к песни) + идемпотентная миграция схемы (`ALTER TABLE ... ADD COLUMN` в try/except при старте); `children_rows` → `lanes_rows(stem)` = `overdub_of = stem OR lane_of = stem`.
- `POST /api/gallery/{stem}/import-lane?title=` — сырые байты аудио (multipart не ставился, как в /api/midi2abc), лимит 100 МБ; ffmpeg → FLAC 48к стерео PCM24 в `outputs/<new-stem>.flac`; строка в БД: title, duration, `lane_of = stem`; появляется слоем в студии и в миксе.

## 2. Новые операции аранжировки в `POST /edit` (набор изменений)

К существующим (trim/fade/gain/chain) добавляются: `silence` (тишина на выделении), `duplicate` (повтор выделения ×N после него), `insert-from` (вставить фрагмент [src_from,src_to] в позицию плеяхеда — копировать/вставить), `swap` (поменять местами два непересекающихся фрагмента), `fade-region` (фейды на краях выделения).
- Таймлайн-трансформации обобщаются: вырезы (cuts) + **вставки (inserts)** — регионы последующих операций пересчитываются в обе стороны; латент строится **инкрементально** зеркально каждой структурной операции (срез/вставка/дубль кадров 25/с), а не только нарезкой в конце; score-таймлайн адаптируется под cuts+inserts.
- `preview: true` в теле /edit — прогнать весь набор во временный `<stem>.d/edit-preview.flac` и вернуть url, **не создавая версию** («прослушать, что получится»).

## 3. Компинг версий

`POST /api/gallery/{stem}/comp {parts: [{stem, from_sec, to_sec}]}` — части только из своей группы (version_root), конкатенация фрагментов разных версий → новая версия «комп: ориг[0–30] + v1[40–80]»; латент = склейка латентов частей; таймлайн секций — best-effort из партитур частей.

## 4. Экспорт

- `GET /api/gallery/{stem}/export?from=&to=&fmt=flac|mp3` — срез выделения в файл (кеш в .d/), скачивание, без создания версии.
- `GET /api/gallery/{stem}/export-multitrack` — zip: основной трек + все слои отдельными flac (кеш в .d/).
- В шапке студии меню «⤓ экспорт»: песня (flac/mp3 — уже есть), выделение, мультитрек.

## 5. Студия — многодорожечный таймлайн (studio.html/js, рестак)

- **Слой-стек вместо одной волны:** линейка+секции отдельным канвасом, под ней дорожки: шапка (имя, гейн 0–1.5, мьют, соло) + канвас волны; основной трек — текущая версия, ниже — слои (/lanes + импорт). Общая X-шкала: выделение/зум/плеяхед сквозь все дорожки.
- **Реальное время через Web Audio:** flac дорожек декодируются в AudioBuffer (лениво), каждая дорожка — GainNode; мьют/соло/гейн слышны мгновенно при игре; seek/луп — пересоздание источников; секционные чипы/ABC-таймлайн работают как сейчас. One-shot прослушивания (превью эффекта, «прослушать набор», соло) — через скрытый `<audio>`.
- **Аранжировка (Audacity-стиль):** кнопки «копировать» (запоминает выделение), «вставить → в плеяхед» (insert-from), «дублировать», «тишина», «поменять местами» (два выделения: первое запоминается, второе завершает), «фейды на выделении» — всё в существующий набор изменений; undo/redo набора (↶ ↷ + Ctrl+Z/Y).
- **Компинг-панель:** «＋ взять выделение из этой версии» (работает при переключении версий в ленте), список частей, «собрать комп → версия».
- **Импорт аудио** — кнопка в «Овердабе и слоях»: файл (mp3/wav/flac/…) → новый слой.
- **Полировка:** Space/Home/End/←/→, Del = вырезать выделение, snap выделения к границам секций (тумблер), «прослушать набор».
